# TrainFlex v5

Mobile PWA mit lokalem Speicher.

## Update über GitHub Pages
1. Inhalt dieses Ordners in das bestehende Repository hochladen und vorhandene Dateien ersetzen.
2. GitHub Pages bleibt auf Branch `main` und Ordner `/root`.
3. App einmal vollständig schließen und neu öffnen.

## Daten
V5 verwendet `trainflex-v5` in LocalStorage und versucht beim ersten Start Daten aus `trainflex` oder `trainflex-v4` zu übernehmen. Vor einem Update empfiehlt sich trotzdem ein Backup der bisherigen Daten.

## Enthalten
- Übungen und Sätze im laufenden Training ergänzen/löschen
- letzte Werte plus regelbasierte Empfehlung
- Material-Infobutton und Ausführungsart
- feste Vorlagenreihenfolge
- All-out als Wiederholungswert
- keine Bestätigungshaken
- verschiebbare Übungsreihenfolge und Speicherung in der Historie
